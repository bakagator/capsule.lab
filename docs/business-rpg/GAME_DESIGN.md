# 経営学RPG「つむぎ堂クロニクル」ゲームデザイン書

> 祖母の小さな和菓子店を継いだ主人公が、商店街の一店舗から世界企業へと成長させていく物語。
> 遊んでいるうちに、経営学の基礎から応用までを「使える知識」として身につけられることを目指す。

---

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| ジャンル | ストーリー型 RPG ＋ 経営シミュレーション |
| 対象 | 経営学を初めて学ぶ大学生・社会人（中級モードでMBA入門レベルまで） |
| プレイ時間 | 全9章・約15〜20時間（1章あたり1.5〜2時間） |
| プラットフォーム | Web（Next.js / このリポジトリ）、スマホ対応 |
| 学習ゴール | 主要な経営理論・フレームワーク約60個を「説明できる」「使える」「状況に応じて選べる」状態にする |

### 1.1 デザインの柱

1. **フレームワーク＝スキル**
   SWOT や 4P などの理論を「覚える知識」ではなく「戦闘で使うスキル」として扱う。正しい場面で正しいスキルを使うと効果が大きい。
2. **敵＝経営課題**
   「赤字の霧」「価格競争ゴーレム」「離職の亡霊」など、モンスターは現実の経営課題の擬人化。弱点を見抜くこと自体が学習になる。
3. **HP＝キャッシュ**
   黒字でも現金が尽きればゲームオーバー（黒字倒産）。会計・財務の重要性を体で覚える。
4. **正解が一つではない意思決定**
   章の山場は「ケース・ディシジョン」。トレードオフのある選択肢から選び、その結果が後の章にも影響する。
5. **基礎→応用の積み上げ**
   前の章で覚えたスキルが、後の章の敵を倒す前提になる（例：損益分岐点が分からないと価格戦略のボスに勝てない）。

## 3. カリキュラムとストーリー構成（全9章）

難易度は **基礎（序〜3章）→ 標準（4〜6章）→ 応用（7〜終章）** の3段階。

### 序章「のれんを継ぐ日」— 経営とは何か 【基礎】

- **ストーリー**：祖母が倒れ、主人公が店を継ぐことに。帳簿を開くと赤字続き。フクロウ先生が現れる。
- **学ぶこと**
  - 企業の目的と経営理念（ミッション・ビジョン・バリュー）
  - 経営資源（ヒト・モノ・カネ・情報）
  - ステークホルダー（顧客・従業員・取引先・地域・株主）
- **ゲーム要素**：チュートリアル戦闘。ステータス画面の見方＝経営資源の把握。
- **獲得スキル**：`理念の旗`、`資源スキャン`

### 第1章「赤字の霧」— 会計の基礎 【基礎】

- **ストーリー**：なぜ売れているのにお金がないのか？ 算盤さんと帳簿の謎を解く。
- **学ぶこと**
  - 損益計算書（PL）・貸借対照表（BS）・キャッシュフロー計算書（CF）
  - 固定費と変動費、損益分岐点分析
  - 黒字倒産のメカニズム
- **ボス**：**赤字の霧**（固定費が見えないと攻撃が当たらない。`損益分岐点` で霧を晴らす）
- **ケース・ディシジョン**：「看板商品の値上げ」vs「人気のない商品の廃止」vs「営業時間の短縮」
- **獲得スキル**：`PLリーディング`、`損益分岐点`、`キャッシュ・ガード`

### 第2章「お客様は誰だ」— マーケティングの基礎 【基礎】

- **ストーリー**：幼なじみユイが帰郷。「誰に売りたいの？」の一言から店の再定義が始まる。
- **学ぶこと**
  - 3C分析（顧客・競合・自社）
  - STP（セグメンテーション・ターゲティング・ポジショニング）
  - マーケティング・ミックス（4P）、カスタマージャーニー
- **ボス**：**無関心の巨人**（全方位攻撃は効かない。STPでターゲットを絞ると弱点が露出）
- **ケース・ディシジョン**：観光客向けの手土産路線か、地元の日常使い路線か
- **獲得スキル**：`3Cスコープ`、`STPランス`、`4Pコンボ`

### 第3章「源さんの背中」— 組織と人材 【基礎】

- **ストーリー**：店が忙しくなりアルバイトを雇うが、すぐ辞めてしまう。源さんとの世代間対立も勃発。
- **学ぶこと**
  - モチベーション理論（マズロー、ハーズバーグの二要因理論、期待理論）
  - リーダーシップ理論（状況対応型リーダーシップ、PM理論）
  - 組織構造の基礎（職能別組織）、権限委譲
  - 暗黙知と形式知（SECIモデル）— 源さんの技術をマニュアル化
- **ボス**：**離職の亡霊**（給与アップ＝衛生要因だけでは倒せない。動機づけ要因で攻める）
- **仲間システム解放**：従業員を「仲間」として雇い、配置できるようになる
- **獲得スキル**：`二要因の見極め`、`SECIの環`、`状況対応リーダーシップ`

### 第4章「黒船チェーン来襲」— 競争戦略 【標準】

- **ストーリー**：ライバル黒川レイの大手チェーンが商店街の目の前に出店。価格競争を仕掛けてくる。
- **学ぶこと**
  - SWOT分析、PEST分析
  - ファイブフォース分析
  - ポーターの3つの基本戦略（コストリーダーシップ・差別化・集中）
  - 資源ベース理論（VRIO）、バリューチェーン
- **ボス**：**価格競争ゴーレム**（値下げで対抗するとこちらのキャッシュが削られる罠。差別化・集中で回避）
- **ケース・ディシジョン**：真っ向勝負／ニッチ集中／商店街連合を組む
- **獲得スキル**：`SWOTの四象限`、`ファイブフォース`、`差別化の刃`、`VRIO鑑定`

### 第5章「工場をつくる」— オペレーションと財務 【標準】

- **ストーリー**：通販が当たり、生産が追いつかない。工場建設のための資金調達に挑む。マダム金森が登場。
- **学ぶこと**
  - 生産管理（QCD、ボトルネック／制約理論、在庫管理、リーン生産）
  - サプライチェーンマネジメント
  - 投資評価（NPV、IRR、回収期間法）
  - 資金調達（デット vs エクイティ）、資本コスト（WACCの考え方）
- **ボス**：**ボトルネック・ワーム**（最も遅い工程を見つけて叩かないと何度でも再生する）
- **サブボス**：**資金ショートの淵**（投資判断を誤ると落ちるダンジョン）
- **ケース・ディシジョン**：銀行融資／投資家からの出資／クラウドファンディング
- **獲得スキル**：`ボトルネック・ハント`、`NPVの天秤`、`ジャストインタイム`

### 第6章「次の柱を探せ」— 成長戦略と企業戦略 【標準】

- **ストーリー**：和菓子だけでは頭打ち。カフェ事業、海外輸出、他社買収……どの道に進むか。
- **学ぶこと**
  - アンゾフの成長マトリクス
  - 多角化と範囲の経済、シナジー
  - PPM（プロダクト・ポートフォリオ・マネジメント）
  - M&A・アライアンス、事業部制組織への移行
- **ボス**：**多角化ヒドラ**（首＝事業を増やしすぎると制御不能に。PPMで切るべき首を見極める）
- **ケース・ディシジョン**：老舗洋菓子店の買収提案を受けるか
- **獲得スキル**：`アンゾフの羅針盤`、`PPMの星図`、`シナジー連鎖`

### 第7章「破壊者の影」— イノベーションとDX 【応用】

- **ストーリー**：AIで最適化された配合を持つ新興フードテック企業が市場を席巻。成功している既存事業ほど変われない。
- **学ぶこと**
  - イノベーションのジレンマ（持続的 vs 破壊的イノベーション）
  - 両利きの経営（知の深化と探索）
  - リーンスタートアップ（MVP、Build-Measure-Learn）
  - デザイン思考、データドリブン経営、プラットフォーム戦略
- **ボス**：**ジレンマの双頭竜**（既存事業を守る頭と、新事業を潰す頭。両方を同時に相手にする必要がある）
- **ケース・ディシジョン**：新規事業を本体でやるか、出島（別組織）でやるか
- **獲得スキル**：`両利きの構え`、`MVPショット`、`データの眼`

### 第8章「世界と信頼」— グローバル経営とガバナンス 【応用】

- **ストーリー**：海外進出。同時に、謎のコンサル・ゼロの正体（不正会計を促す元経営者）が明らかになり、社内で不祥事の芽が見つかる。
- **学ぶこと**
  - 国際経営（CAGEフレームワーク、参入モード、グローバル統合 vs 現地適応）
  - 異文化マネジメント（ホフステードの文化次元）
  - コーポレートガバナンス、内部統制、企業倫理
  - CSR・ESG・サステナビリティ経営、リスクマネジメント
- **ボス**：**ゼロ**（短期利益を餌に誘惑してくる。誘惑に乗った回数で強さが変わる）
- **獲得スキル**：`CAGEの距離計`、`ガバナンスの盾`、`ESGの調和`

### 終章「経営者になる」— 統合ケース 【応用・総合】

- **ストーリー**：祖母の言葉の本当の意味を知る。黒川レイとの協業、そして100年続く会社のビジョンを描く。
- **内容**：これまでの全スキルを使う統合ケース。業績・従業員満足・地域・環境のバランスでエンディングが分岐。
- **最終ボス**：**停滞（ステイシス）**— 全属性を持ち、状況に応じてフレームワークを選択・組み合わせないと倒せない。
- **マルチエンディング**（後述 §6）

## 4. ゲームシステム

### 4.1 ステータス設計

**経営者ステータス（主人公）** — レベルアップで成長

| ステータス | 意味 | 影響 |
|---|---|---|
| 分析力 | 情報を読み解く力 | 分析系スキルの威力、敵の弱点の表示精度 |
| 判断力 | 意思決定の質 | クリティカル率、ケース・ディシジョンの選択肢追加 |
| 統率力 | 人を動かす力 | 仲間（従業員）の能力補正 |
| 創造力 | 新しい価値を生む力 | イノベーション系スキルの威力 |
| 交渉力 | 利害を調整する力 | 資金調達・提携イベントの成功率 |
| 体力（MP） | 経営者の時間とエネルギー | スキル使用で消費。休息・権限委譲で回復 |

**会社ステータス** — 意思決定で変動

| ステータス | 意味 | ゲーム上の役割 |
|---|---|---|
| **キャッシュ（HP）** | 手元資金 | 0になるとゲームオーバー（黒字倒産を含む） |
| 売上・利益 | PLの数字 | 毎ターン（＝1か月）決算で更新 |
| ヒト | 人材の数と質 | 仲間の枠数、離職率 |
| モノ | 設備・商品力 | 生産キャパシティ、品質 |
| 情報 | データ・ノウハウ | 敵の情報開示、スキル解放条件 |
| ブランド | 顧客からの信頼 | 売上の安定性、危機時の防御力 |
| 従業員満足 / 地域評価 / 環境評価 | 非財務指標 | エンディング分岐の条件 |

### 4.2 経営バトル（戦闘システム）

ターン制コマンドバトル。**敵＝経営課題**、**スキル＝フレームワーク・理論**。

```
[ 敵：価格競争ゴーレム ]   属性：競争 / 弱点：??? （分析で判明）
-----------------------------------------------
▶ スキル    ― SWOTの四象限 / 差別化の刃 / 値下げ（罠）
  分析      ― 敵の弱点・状態を調べる（クイズ形式）
  仲間      ― 従業員に指示（ユイ：マーケ支援 など）
  アイテム  ― 補助金・融資・知恵袋（ヒント）
```

- **属性相性**：課題には属性（会計・マーケ・組織・戦略・財務・技術・倫理）がある。属性に合ったスキルで大ダメージ。
- **分析フェーズ**：敵の弱点は最初「???」。ミニクイズ（例：「この店の固定費はどれ？」）に正解すると弱点が判明。理解していないと攻略できない＝学習のゲート。
- **罠コマンド**：「値下げ」「リストラ」「粉飾」など、一見効きそうだが長期的に悪影響を与えるコマンドが混ざる。使うと短期的にはダメージを与えるが、キャッシュやブランドが削られる。
- **コンボ**：関連する理論を順番に使うとコンボ発動（例：`3Cスコープ` → `STPランス` → `4Pコンボ` ＝「マーケティング・プロセス」ボーナス）。理論同士のつながりを学ばせる。
- **戦闘後の振り返り**：「なぜそのスキルが効いたのか」をフクロウ先生が30秒で解説。

### 4.3 ケース・ディシジョン（章の山場）

ビジネススクールのケースメソッドをゲーム化したもの。

1. **状況提示**：数字（PL、市場データ）と登場人物の意見が提示される
2. **分析**：獲得済みスキルを使って情報を整理（使ったスキルに応じて追加情報が開示）
3. **意思決定**：3〜4つの選択肢から選ぶ。**明確な正解はなく、トレードオフがある**
4. **結果**：数ターン後に結果が反映。選ばなかった選択肢の「もしも」も見られる
5. **振り返り**：判断の根拠を3択で選ばせ、論理の一貫性を評価（結果ではなくプロセスを評価）

### 4.4 経営ターン（シミュレーションパート）

- フィールド移動とは別に、1ターン＝1か月の経営フェーズがある
- 予算配分（広告・人材・設備・研究開発）を決め、月次決算でPL/BS/CFが更新される
- 実際の財務諸表の形式で表示し、数字を読む練習を自然に繰り返す

### 4.5 仲間（従業員）システム（3章〜）

- 従業員には「スキル」「モチベーション」「価値観」があり、配置と育成で能力が変わる
- モチベーションは二要因理論に基づき、衛生要因（給与・環境）と動機づけ要因（承認・成長・裁量）で管理
- 権限委譲すると主人公の体力（MP）消費が減るが、育成が不十分だとミスが起きる

### 4.6 成長システム

| 要素 | 内容 |
|---|---|
| 経験値 | 戦闘・クイズ・ケース・ディシジョンで獲得 |
| スキルツリー | 「会計・財務」「マーケティング」「組織・人材」「戦略」「オペレーション」「イノベーション」の6系統 |
| スキル熟練度 | 同じスキルを適切な場面で使うと熟練度が上がり、上位スキルに進化（例：`SWOTの四象限` → `クロスSWOT`） |
| 経営学図鑑 | 出会った理論・用語・提唱者を収集。図鑑のコンプリート率が学習進捗の可視化になる |

## 5. 学習デザイン

### 5.1 3段階の学習ループ

各理論は次の3段階で登場する（ブルームのタキソノミーを簡略化）。

| 段階 | ゲーム内の形 | 目標 |
|---|---|---|
| **知る** | NPCの会話、フクロウ先生の講義、図鑑 | 用語と概念を説明できる |
| **使う** | 経営バトル、分析クイズ | 与えられた場面でフレームワークを適用できる |
| **選ぶ** | ケース・ディシジョン、終章の統合ケース | 状況に応じて適切な理論を選び、組み合わせられる |

### 5.2 定着のしかけ

- **復習ダンジョン「忘却の迷宮」**：過去に学んだスキルの敵が間隔をあけて再出現（間隔反復）
- **ヒントの段階化**：間違えると「ヒント1（考え方）→ヒント2（具体例）→解答と解説」の順で開示
- **実在企業のケース**：各章のエピローグで、学んだ理論に関連する実在企業の事例をコラムとして紹介（事実関係はリリース前に要確認）
- **章末テスト「経営者認定試験」**：10問。合格で次章の解放＋称号獲得

### 5.3 難易度モード

| モード | 対象 | 違い |
|---|---|---|
| 入門 | 高校生〜大学1年 | ヒント多め、計算問題は選択式 |
| 標準 | 大学生・社会人 | 標準 |
| MBA | 経営学既習者 | 計算問題は数値入力、ケース・ディシジョンの情報量が多い、罠コマンドが巧妙 |

## 6. エンディング分岐

終章時点の指標で分岐する。「利益だけ」「理想だけ」では最良のエンディングにならない設計。

| エンディング | 条件の例 | テーマ |
|---|---|---|
| **百年企業**（トゥルー） | 財務・従業員・地域・環境のすべてが基準以上 | ステークホルダー経営 |
| 巨大企業 | 売上は最大だが従業員満足・地域評価が低い | 成長の代償 |
| 愛される小さな店 | 財務は安定、規模は小さいが地域評価が最高 | 集中戦略という選択 |
| 売却 | 途中で買収提案を受諾 | 出口戦略（EXIT）もひとつの経営判断 |
| ゼロの末路（バッド） | ゼロの誘惑に複数回乗る | ガバナンスの崩壊 |

## 8. サンプルシナリオ（第1章ボス戦）

```
【赤字の霧が現れた！】
フクロウ先生「霧のせいで敵の正体が見えんのう。まずは"分析"じゃ」

▶ 分析
Q. つむぎ堂の費用のうち「固定費」はどれ？（2つ選ぶ）
   [x] 店舗の家賃（月20万円）
   [ ] 小豆・砂糖の仕入れ
   [x] 源さんの給料（月25万円）
   [ ] 包装紙代
→ 正解！ 霧が少し晴れた。固定費合計：45万円/月

Q. 大福1個：価格200円、変動費80円。損益分岐点の販売数は月何個？
   ① 2,250個  ② 3,750個  ③ 5,625個
→ 正解は②（45万円 ÷ (200円−80円) = 3,750個）
   赤字の霧の弱点「損益分岐点」が判明した！

▶ スキル：損益分岐点
→ 会心の一撃！ 赤字の霧の正体は「売上が損益分岐点に届いていない」ことだった。

フクロウ先生の振り返り：
「利益を出すには『もっと売る』『値段を上げる』『変動費を下げる』『固定費を下げる』の4つの道しかない。
 次のケース・ディシジョンで、どの道を選ぶか考えてみるのじゃ」
```
