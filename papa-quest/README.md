# パパクエスト 👨‍🍼

子育てパパ向けの、ゲームで学ぶ育児準備アプリ（まつだ家アプリとは独立した Next.js アプリ）。

- 💐 ママへの気遣いクエスト（シチュエーションクイズ）
- 🗺️ パパの成長マップ（妊娠初期〜1歳、月ごとの心の準備とミッション）
- 🎓 両親学級オンライン（沐浴・おむつ・抱っこ・睡眠・陣痛・妊婦の体）
- 💨 ゲップ名人チャレンジ（抱き方＋トントンのタイミングゲーム）
- 🍼 ミルク職人への道（手順ならべ＋温度調整ゲーム）

進捗（XP・レベル・バッジ）はブラウザの localStorage に保存されます。
問題文やミッションは `src/lib/papa/data.ts` で編集できます。

## 開発

```bash
cd papa-quest
npm install
npm run dev
```
